# 截图放置说明

把截图按下面的文件名放进 `public/screenshots/`，页面会自动显示，**不需要改任何代码**。
缺哪一张就显示哪一张的占位，构建不受影响（文件不存在只会 404，不会让构建失败）。

| 文件名 | 内容 | 页面位置 |
| --- | --- | --- |
| `main.png` | 主界面：侧栏 + 曲库 + 底部播放器 | Hero 右侧，单张大图 |
| `lyrics.png` | 全屏沉浸歌词 | 「歌词是主业」那节，两列左 |
| `desktop-lyrics.png` | 桌面歌词条 | 「歌词是主业」那节，两列右 |
| `mv.png` | MV 沉浸页 | 「还有这些」一行三张，左 |
| `search.png` | 搜索结果与综合分段 | 「还有这些」一行三张，中 |
| `mini-player.png` | 小窗（迷你播放器） | 「还有这些」一行三张，右 |

## 尺寸

**统一按 16:10 出图**，推荐 1440 × 900。窗口外框的比例固定 16:10，
别的比例会被 `object-fit: cover` 裁掉上下或左右。

小窗（`mini-player.png`）也请裁成 16:10。小窗本身是 3:2 的，直接截会左右被裁，
建议连它后面的桌面一起截，再裁成 16:10。

## 注意

- 文件名必须完全一致，大小写敏感（部署到 GitHub Pages 的 Linux 环境时尤其如此）。
- 只放 PNG。想换格式要同时改 `src/data/site.ts` 里的 `file` 字段。
- 截图里不要带真实账号信息。页面是公开的。
- 单张控制在 1 MB 以内，用 `optipng` 或 `pngquant` 压一下再用。
- 想换位置或增删，改 `src/data/site.ts` 里的 `screenshots` 与 `gallery` 两组编排，组件不用动。
