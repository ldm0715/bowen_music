# 歌词页左侧：老式磁带机

**日期：2026-11-06。** 全屏歌词页左侧封面槽新增第四种样式「磁带机」：
一台正视图的银色便携磁带机，正面仓窗里能看到磁带、两个磁轮与走带机构，
播放时磁轮转动，底部一排机械按键可直接操作播放。**已实现，已提交。**

## 1. 结论与边界

- **纯正视图。** 仓门、仓窗、磁带、磁轮、按键全部画在正面，不画俯视、顶面或 3/4 视角。
  按键是正面机身上的一排实体键，不是浮在机身上方的顶面键帽。
- **没有屏幕。** 磁带机不带显示屏；曲名与歌手印在磁带的纸标签上，
  专辑封面也印在同一张纸上，换歌即换磁带。
- **要有真的机械结构。** 两个磁轮画出磁带层的同心圆、辐条与轮毂；
  两个卷带孔里能看到深灰卷盘环、轮毂与连接左右卷盘底缘的带基，压带轮与磁头藏在
  磁带后面，不是两块装饰圆。
- **纯 XAML 矢量 + 一处合成裁剪，不引入新依赖。** 机身按 320×320 设计稿绘制，
  整层按封面槽尺寸等比缩放；不做 3D。只有「封面被纸标签的卷带孔挖穿」这一处用
  `CompositionGeometricClip` 裁剪封面，几何由已有的 Win2D 依赖生成。
- **切歌有换带动作。** 开盖 → 旧磁带向下滑出 → 新磁带从下方推入 → 盖盖；
  动作约 0.9 秒，连续切歌时版本号让上一轮作废。
- **带量随播放进度变化。** 供带轮（左）从满盘逐渐变小，收带轮（右）相反变满；
  两轮仍然同速转，但磁带层直径会随时间更新。

## 3. 造型（320×320 设计稿）

| 部件 | 规格 | 画法 |
| --- | --- | --- |
| 机身 | 248×300，圆角 12，画布内居中（左 36、上 10） | 老式银灰塑料：上亮下暗的竖向渐变，顶部亮边、底部暗边 |
| 投影 | 216×12 椭圆，机身正下方 | 径向渐变，把机器压在桌面上 |
| 正面仓门 | 224×214，圆角 8，上 26 | 比机身深一档的凹面 + 细描边；右侧一个小卡扣，底部两颗铰链 |
| 仓窗 | 200×150，圆角 4，上 40 | 近黑内腔 + 一圈亮边，磁带嵌在里面 |
| 磁带本体 | 190×138，圆角 2 | 米白色塑料壳，透过仓窗可见 |
| 纸标签 | 168×114，圆角 2.5，左 76、上 58 | 米白纸面，覆盖磁带正面约 73%；只在左右两个磁轮处挖圆孔，中间整块留给封面 |
| 卷带孔 | 直径 48，圆心 (100,112) / (220,112) | 与纸标签左右两边相切；用偶奇规则穿透纸面与封面，孔里是磁轮卷盘、轮毂与播放器的固定铜柱，孔上一道极淡的玻璃反光 |
| 专辑封面 | 92×92，圆角 2，左 114、上 62 | 印在纸标签上，`DetailCover` 用 Uniform 完整显示整张封面、不裁切；只在左右两侧被圆孔咬掉，中间画面完整 |
| 曲名 / 歌手 | 纸标签下沿，宽 168 | 曲名 7 DIP、歌手 5.5 DIP，深灰字印在纸面上，随磁带一起滑出 |
| 磁带印刷 | 纸标签左右两条留白 | STEREO / TYPE II / 60 MIN / SIDE A，小号灰字，只做装饰 |
| 左 / 右磁轮 | 卷盘环外径 28..40，圆心 (100,112) / (220,112) | 深灰圆环表示绕上去的磁带厚度，环上五道浅色同心纹读出圈数；轮毂 + 辐条，轴心是播放器的固定铜柱；换带时随磁带移出 |
| 带基 | 1.5 DIP 的深灰线，闭环一笔画完 | 沿左盘外缘半圈 → 下切线 → 右盘外缘半圈 → 上切线；切线斜率随两边半径差变化，切点压在外缘上，和卷盘同色无端头；中段被纸标签盖住，只在卷带孔里露出来 |
| 铜柱 | 直径 12，圆心与磁轮相同，压在磁带之上 | 黄铜色小柱 + 轴孔，属于播放器的固定件；卷盘绕它转，换带时它留在原地 |
| 磁轮转速 | 120°/s，两轮同向 | 3 秒一圈；辐条让转动看得出来 |
| 机芯 | 带路中间 | 两个压带轮与一个磁头，在磁带后面；装带时被挡住，换带时才露出来 |
| 底部按键 | 上一首 40×26、播放 60×26、停止 40×26、下一首 40×26 | 正面实体键：深炭灰渐变 + 顶部玻璃高光 + 底部内阴影，播放键红色；键下印 PREV / PLAY / STOP / NEXT |
| 印刷字 | 5–6.5 DIP | 「BOWEN」「AUTO REVERSE」，透明度约 60%，只做装饰 |
| 刻度 | 底部一排 24 根短竖线 | code-behind 批量生成，放在机身下沿 |

按键是真正的 `Button`，键盘焦点、无障碍、按下态都走系统；播放键里的图标随播放状态切换。

### 3.1 层序

`CoverDeck` 是 `Canvas`，磁带机按「机身 → 磁带 → 纸标签 → 封面 → 玻璃」分层：

1. `CassetteDeviceBack`：投影、机身、`CassetteDoorLayer`（仓门、卡扣、铰链）、
   静态仓腔、`CassettePostLayer`（压带轮与磁头，固定）、
   `CassetteTapeLayer`（磁带壳、带基、两个磁轮、纸标签与印刷字，换带时整层滑动）、
   `CassetteSpindleLayer`（两根铜柱，固定，压在磁带之上并落在卷带孔里）、螺丝与刻度，
   位于 `VinylClipHost` 之下；
2. `VinylClipHost` 里的 `CoverFrame`：`DetailCover` 是纸标签上的封面，**在磁轮之上**，
   两个卷带孔范围内被合成裁剪挖掉；换带时的旧封面遮罩 `CoverSwapLabel` 也在这一层，
   用同一个裁剪；
3. `CassetteDeviceFront`：`CassetteGlass` 仓窗玻璃、底部按键与机身印刷字。

前后两层都用 `ScaleTransform(size / 320)` 缩放，纸标签、封面与机身始终保持对齐。

## 4. 交互映射

| 控件 | 动作 | 绑定 |
| --- | --- | --- |
| 红色播放键 | 切换播放 / 暂停 | `Player.TogglePlayPauseCommand` |
| 上一首键 | 上一曲 | `Player.PreviousCommand` |
| 停止键 | 播放中按下才暂停，已暂停时不响应 | `OnCassetteStopClick` |
| 下一首键 | 下一曲 | `Player.NextCommand` |

状态：

- 磁轮在「磁带机样式 + 播放中 + 页面可见 + 未挂起 + 不在入场动画中 + 未等待跳转」时转，
  条件与黑胶完全一致；暂停时从当前角度停住，继续播放接着转。
- 复用现有 16 ms 定时器：新增 `_cassetteSpinning` / `_cassetteAngle`，
  与黑胶旋转互斥，不另起一条定时器。
- 切样式时把磁轮角度归零并停表，避免下次进入时从一个奇怪的角度开始。
- **换带**：切歌时按四拍走——仓门绕底边向下折（玻璃同步淡出），旧磁带壳、
  两个磁轮、纸标签连同封面一起向下滑出并淡出，换成新封面后从下方推入，
  最后仓门盖回、玻璃淡入。只有 `CassetteTapeLayer` 与 `VinylSpinLayer` 参与滑动：
  机身、仓腔、压带轮与磁头（`CassettePostLayer`）、两根固定铜柱
  （`CassetteSpindleLayer`）都留在原地。
  旧封面用 `CoverSwapLabel` 盖住，纸标签上的曲名也按住上一首，等新磁带推入前才换字；
  系统关闭动画时直接换图。
  连续快速切歌时 `_cassetteSwapVersion` 让上一轮未完成的步骤作废。
- **带量**：按 `PositionSeconds / DurationSeconds` 把供带轮从 1.0 缩到空盘、
  收带轮从空盘长到 1.0；空盘时卷盘环缩到轮毂外沿（0.425），看起来只剩轮毂。
  开头收带轮是空的，播完供带轮变空，两边跟进度线性同步。
  环按比例整体缩放，轮毂与辐条不参与缩放；履带路径同时按两边半径重算，
  跳转进度或切歌时立即更新。
- **纸标签与卷带孔**：纸标签覆盖磁带正面约七成，整张纸在磁轮之上；只在左右两个磁轮处
  挖直径 48 的圆孔，中间整块留给封面，不再用横窗把画面拦腰截断。纸标签用 `Path`
  的偶奇规则挖洞，封面用 `CompositionGeometricClip` 裁掉同两个圆，两者在 320 设计稿
  坐标里对齐后再一起等比缩放。圆孔里是深灰卷盘环、播放器的固定铜柱，以及绕在两个
  卷盘外圈的闭环带基；纸标签中段把带基盖住，所以只在透明孔里看得到它。
  裁剪只加在
  `DetailCover` 与换带遮罩的视觉上，不改它们的布局与可见性，不影响共享封面动画。
- 无曲目时整个封面槽隐藏，沿用 `CoverDeck` 的 `Player.HasTrack` 绑定。

## 5. 暂不做的取舍

- **仓门只做二维折下**：用竖向压扁模拟绕底边推开，没有真正的 3D 旋转；
  正视图下这个动作足够读得懂，也不引入 PlaneProjection。
- **两轮同速**：带量会变，但供带轮与收带轮的角速度没有按半径反比变化；
  在当前尺寸下差速看不出来，收益低于复杂度。
- **不做顶部视角的立体按键**：老式磁带机的按键在正面下沿，俯视会把机器画成两个面，
  与封面槽的正视图不搭。
