# 歌词页左侧：老式磁带机

**日期：2026-11-06。** 全屏歌词页左侧封面槽新增第四种样式「磁带机」：
一台正视图的银色便携磁带机，正面仓窗里能看到磁带、两个磁轮与走带机构，
播放时磁轮转动，底部一排机械按键可直接操作播放。**已实现，已提交。**

## 1. 结论与边界

- **纯正视图。** 仓门、仓窗、磁带、磁轮、按键全部画在正面，不画俯视、顶面或 3/4 视角。
  按键是正面机身上的一排实体键，不是浮在机身上方的顶面键帽。
- **没有屏幕。** 磁带机不带显示屏；曲名与歌手印在仓门下方的铭牌上，
  专辑封面贴在磁带的纸质标签上，换歌即换磁带。
- **要有真的机械结构。** 两个磁轮画出磁带层的同心圆、辐条与轮毂；
  两轮之间是走带路径，压带轮与磁头藏在磁带后面，不是两块装饰圆。
- **纯 XAML 矢量，不引入新依赖。** 机身按 320×320 设计稿绘制，
  整层按封面槽尺寸等比缩放；不做 3D、不用 Win2D。
- **切歌有换带动作。** 开盖 → 旧磁带向下滑出 → 新磁带从下方推入 → 盖盖；
  动作约 0.9 秒，连续切歌时版本号让上一轮作废。
- **带量随播放进度变化。** 供带轮（左）从满盘逐渐变小，收带轮（右）相反变满；
  两轮仍然同速转，但磁带层直径会随时间更新。

## 3. 造型（320×320 设计稿）

| 部件 | 规格 | 画法 |
| --- | --- | --- |
| 机身 | 248×300，圆角 12，画布内居中（左 36、上 10） | 老式银灰塑料：上亮下暗的竖向渐变，顶部亮边、底部暗边 |
| 投影 | 216×12 椭圆，机身正下方 | 径向渐变，把机器压在桌面上 |
| 正面仓门 | 224×214，圆角 8，上 26 | 比机身深一档的凹面 + 细描边；右侧一个小卡扣，底部两颗铰链 |
| 仓窗 | 200×150，圆角 4，上 40 | 近黑内腔 + 一圈亮边，磁带嵌在里面 |
| 磁带本体 | 190×138，圆角 2 | 米白色塑料壳，透过仓窗可见 |
| 专辑贴纸 | 96×96，圆角 2，左 112、上 67 | 正方形贴纸，`DetailCover` 用 Uniform 完整显示整张封面、不裁切；贴在磁带正中，在磁轮之上 |
| 磁带印刷 | 贴纸上下的留白 | STEREO / 60 MIN / TYPE II · NORMAL POSITION / SIDE A，小号灰字，只做装饰 |
| 左 / 右磁轮 | 磁带卷直径 54 → 约 17，圆心 (100,112) / (220,112) | 磁带卷本身就是可见的圆，同心圆表示层数；六根短辐条 + 轮毂 + 中孔；坐在两根铜柱上，换带时随磁带移出 |
| 铜柱 | 直径 12，圆心与磁轮相同 | 黄铜色小柱 + 轴孔，固定在机器里；换带后只留下它 |
| 磁轮转速 | 120°/s，两轮同向 | 3 秒一圈；辐条让转动看得出来 |
| 走带路径 | 贴纸上方与下方 | 两条横贯磁带壳的走带线，始终可见；属于磁带，换带时跟着滑出 |
| 机芯 | 带路中间 | 两个压带轮与一个磁头，和铜柱同层、在磁带后面；装带时被挡住，换带时才露出来 |
| 曲名铭牌 | 仓门下方，宽 200 | 曲名 9.5 DIP、歌手 7.5 DIP，深色字印在银灰机身上 |
| 底部按键 | 上一首 40×26、播放 60×26、停止 40×26、下一首 40×26 | 正面实体键：深炭灰渐变 + 顶部玻璃高光 + 底部内阴影，播放键红色；键下印 PREV / PLAY / STOP / NEXT |
| 印刷字 | 5–6.5 DIP | 「BOWEN」「AUTO REVERSE」，透明度约 60%，只做装饰 |
| 刻度 | 底部一排 24 根短竖线 | code-behind 批量生成，放在机身下沿 |

按键是真正的 `Button`，键盘焦点、无障碍、按下态都走系统；播放键里的图标随播放状态切换。

### 3.1 层序

`CoverDeck` 是 `Canvas`，磁带机按「机身 → 磁带 → 贴纸 → 玻璃」分层：

1. `CassetteDeviceBack`：投影、机身、`CassetteDoorLayer`（仓门、卡扣、铰链）、
   静态仓腔、`CassettePostLayer`（两根铜柱、两个压带轮与磁头）、
   `CassetteTapeLayer`（磁带壳、走带、两个磁轮）、螺丝与刻度，位于 `VinylClipHost` 之下；
2. `VinylClipHost` 里的 `CoverFrame`：`DetailCover` 铺满贴纸，**在磁轮之上**，
   盖住轮盘靠近中间的部分；换带时的旧封面遮罩 `CoverSwapLabel` 也在这一层；
3. `CassetteDeviceFront`：`CassetteGlass` 仓窗玻璃、曲名铭牌、底部按键与印刷字。

前后两层都用 `ScaleTransform(size / 320)` 缩放，贴纸位置与机身始终保持对齐。

## 4. 交互映射

| 控件 | 动作 | 绑定 |
| --- | --- | --- |
| 红色播放键 | 切换播放 / 暂停 | `Player.TogglePlayPauseCommand` |
| 上一首键 | 上一曲 | `Player.PreviousCommand` |
| 停止键 | 播放中按下才暂停，已暂停时不响应 | `OnCassetteStopClick` |
| 下一首键 | 下一曲 | `Player.NextCommand` |

状态：

- 磁轮在「磁带机样式 + 播放中 + 页面可见 + 未挂起 + 不在入场动画中 + 未等待跳转」时转，
  条件与黑胶完全一致；暂停时从当前角度停住，继续播放接着转。
- 复用现有 16 ms 定时器：新增 `_cassetteSpinning` / `_cassetteAngle`，
  与黑胶旋转互斥，不另起一条定时器。
- 切样式时把磁轮角度归零并停表，避免下次进入时从一个奇怪的角度开始。
- **换带**：切歌时按四拍走——仓门绕底边向下折（玻璃同步淡出），旧磁带壳、
  两个磁轮、走带路径连同标签一起向下滑出并淡出，换成新封面后从下方推入，
  最后仓门盖回、玻璃淡入。磁带后面是两根铜柱（磁带轮毂坐的轴）、压带轮与磁头，
  换带时磁带滑出，它们才露出来。
  旧封面用 `CoverSwapLabel` 盖住，滑出去的仍是上一首；系统关闭动画时直接换图。
  连续快速切歌时 `_cassetteSwapVersion` 让上一轮未完成的步骤作废。
- **带量**：按 `PositionSeconds / DurationSeconds` 把供带轮从 1.0 缩到 0.32、
  收带轮从 0.32 长到 1.0；磁带卷是一组同心圆，按比例整体缩放，轮毂与辐条不参与缩放。
  没有固定外圈，满盘与空盘的直径差接近三倍，左右对比一眼能看出来。
  走带路径也按两侧带卷半径重画，磁带始终从带卷底部离开，不画绕在轮盘外侧的圆弧；
  跳转进度或切歌时立即更新。
- **贴纸遮挡**：贴纸贴在磁带正中，在磁轮之上，盖住轮盘靠近中间的部分；
  轮缘与带卷外侧露在贴纸外面。两条走带线在贴纸上下方横贯磁带壳，始终可见，
  换带时随磁带一起移出。不用裁剪几何，也不会和共享封面动画抢 `DetailCover` 的可见性。
- 无曲目时整个封面槽隐藏，沿用 `CoverDeck` 的 `Player.HasTrack` 绑定。

## 5. 暂不做的取舍

- **仓门只做二维折下**：用竖向压扁模拟绕底边推开，没有真正的 3D 旋转；
  正视图下这个动作足够读得懂，也不引入 PlaneProjection。
- **两轮同速**：带量会变，但供带轮与收带轮的角速度没有按半径反比变化；
  在当前尺寸下差速看不出来，收益低于复杂度。
- **不做顶部视角的立体按键**：老式磁带机的按键在正面下沿，俯视会把机器画成两个面，
  与封面槽的正视图不搭。
