# 歌曲评论界面与接口

2026-10-02：评论列表、详情与回复、文字发布、点赞、图片查看和数量角标已接入。构建使用原来的默认输出目录，不指定额外的 `OutDir`。

## 入口与数量角标

评论入口只在 `LyricsPage` 播放页出现，位于音量左侧；窄窗口隐藏音量滑块时仍保留评论入口。右上角的角标显示歌曲评论总数：

| 总数 | 显示 |
| --- | --- |
| 0 | `0` |
| 9999 | `9999` |
| 10000 | `10000` |
| 10001–10999 | `1w+` |
| 12345 | `1w2+` |
| 27890 | `2w7+` |

超过 10000 时按千位截断，不四舍五入；数量未知或音源不支持评论时隐藏角标。进入播放页按需读取歌曲详情的 `comment` 字段，同一首歌复用已知数量。
2026-10-03 收藏 / 分享统计加入后，评论角标通过共享统计模型复用正在进行或已完成的歌曲详情请求，避免重复读取。打开评论后以列表的 `comment_total` 更新，切歌或离开页面时取消评论角标的旧等待，迟到响应不能覆盖新歌数量；关闭评论等待不取消播放器共享统计请求。不为角标预先加载评论列表。

## 面板、详情与主题

- 右侧面板宽度最多 420 DIP，随窗口收缩，打开时保留播放控制区。
- 默认推荐，可切换最新。评论列表和回复列表均使用虚拟化、固定每页 30 条，并区分首次加载、加载更多、空列表和失败重试。
- 主评论有回复时显示“查看”，没有回复时隐藏；“回复”入口始终保留。详情可以回复主评论或指定的一条回复，回复列表有独立分页和重试。
- 点击面板外、关闭按钮或再次点击评论入口可收起。Esc 依次关闭图片、返回评论列表、关闭面板，再处理退出播放页／全屏。
- 浅色、深色和系统主题均跟随 `MainWindow.ThemeRoot`（实际是 `ShellRoot`）；不能读取外层 `ResponsiveViewport` 的 `ActualTheme`，那里反映的可能只是系统主题。进入时同步主题，离开时解除事件订阅。
- 背景保持完全不透明，避免封面和动态背景干扰阅读：浅色 `#FAFBFD`／正文 `#18212F`，深色 `#171D29`／正文 `#F1F4FA`。输入框、分隔线、属地、强调色、错误提示和图片查看也随主题变化，并提供高对比度资源。

点赞图标使用每个评论行独立的矢量路径，未点赞为轮廓、已点赞为实心，不依赖系统字体是否包含特定码点。不能在回收列表中复用同一个 `PathGeometry`，否则可能在测量评论行时触发 XAML 异常。

## 发布、回复和点赞

登录后可以发送文字评论、回复、点赞和取消点赞，可选择匿名，支持 `Ctrl+Enter` 发送。输入框的 1000 字上限是当前界面约束，未假定为服务端限制。草稿按歌曲／主评论／回复目标隔离，在当前页面实例内最多保留 32 份。

- **点赞／取消点赞**：只有用户点击才发送请求。成功后直接更新实心／轮廓图标和数量，不自动刷新或额外读取列表；失败保持原状态并显示错误。处理中防止重复点击，切歌或关闭后的迟到响应不改新页面状态。
- **发布／回复**：受理后读取最新列表或回复列表确认评论出现。回复按时间正序，新增回复可能在末页，所以还会核对末页。确认后清空草稿；失败或暂未确认时保留草稿并提示，不自动重试写请求。
- **日志**：记录操作、歌曲／评论 id、接口、op、业务码和 reqId，不记录正文和请求凭据。发布额外记录读回确认；点赞记录成功后的界面更新。日志目录为 `%LOCALAPPDATA%\Bodian\logs`。

真实写操作由用户手动实测，助手只读取日志和执行离线测试。用户已验证文字发布／回复；2026-10-02 18:24 的日志也记录了 v3 点赞与取消点赞返回 200 及界面状态更新。点赞交互不自动读回，这些日志不会冒充额外读取确认。

## 评论面板内的图片查看

点击附图后仅覆盖整个评论面板，保留原列表位置和回复上下文，关闭后返回原处。支持放大、缩小、适应面板、双击／滚轮缩放、鼠标左键拖动、触摸平移与双指缩放。缩放范围为适应尺寸的 25%–500%，可平移时显示手形光标和拖动提示；平移限制在图片边界内。

图片请求使用原始 URL，解码宽度按视口和最高倍率限定在 1024–4096 像素，以控制纹理大小。`ImageViewportState` 负责缩放锚点、居中和边界；图像尺寸仅在加载、适应或视口变化时参与布局。鼠标移动只保存最新位移，每个显示帧最多更新一次 Composition 的 `Translation`／`Scale`，不逐事件调用 `ScrollViewer.ChangeView`。渲染事件为一次性订阅，用完或卸载时解除。

## 接口与空状态

| 操作 | 端点 | 关键字段 |
| --- | --- | --- |
| 最新／推荐 | `GET comments/v3/new`／`hot` | `moduleType=2`、`moduleId=musicId`、`pn`、`rn=30` |
| 回复列表 | `GET comments/v3/replies` | 同上，另带主评论 `parentId` |
| 发布／回复 | `POST comments/v3/publish` | `uid`、`moduleType`、`moduleId`、`content`、`anonymous`；回复另带 `parentId`／`replyId` |
| 点赞／取消点赞 | `POST comments/v3/like` | `uid`、`moduleType=2`、`moduleId`、`commentId`、`op=1/2`；回复另带 `parentId` |

评论请求单独覆盖 `plat: android`，沿用 `ver: 1.1.7`，不签名；其他业务仍走桌面请求头。页码从 1 开始，推荐列表 `rn<=21` 有异常，所以固定 30。空的可选发布字段与官方一样省略。v3 歌曲评论的点赞必须走 v3；旧文档“v3/like 仅用于话题”的错误已修正，完整调用链见 [`../reverse/findings/08-comments.md`](../reverse/findings/08-comments.md)。

`comment_list=[]` 是正常空结果，显示“还没有评论”。网络／协议错误显示加载失败及重试。评论服务的 `moduleId` 仅接受 32 位正整数，部分音源的超长 id 显示“这首歌的音源暂不支持评论”，不误报为零评论、不重复请求，也不允许发布。缺少 `data` 不当成正常空列表。
