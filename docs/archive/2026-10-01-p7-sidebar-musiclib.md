## 二、惊险流程：五次踩空

### 5.1 我把「乐库」认成了另一个功能，并且**据此写了一整版界面**

**经过**：用户要「乐库 tab，看不同类型的专辑合集」。
我按 `category` 关键字在二进制里搜到 `service/category/*`，做出了一版「分类 → 歌单」的页面，
还写了测试、做了侧栏项、跑通了冒烟。

**用户看出来的**：「你这个是第三方创建的歌单呀，移动端最新版返回的是官方歌单。」

**真相**：乐库是 `play/music/library/*`（类名 `MusicLib*`，页面中文名「**专辑库**」），
内容是官方按曲风分类的**专辑**；而 `service/category/*` 是「歌单广场」——用户创建的 **UGC 歌单**。
**两者是完全不同的功能。**

**为什么没早发现**：那三个 `MusicLib*` 标识符**只存在于 5.9.8**，而当时我手上的 5.9.8 是 **armeabi-v7a**、
blutter 处理不了，所以我根本没去看最新版，只在 5.2.5 的产物里搜 —— 那里面一个都没有。

**本可以怎么避免**：**用户说的是「专辑合集」，而我做出的东西是歌单。**
如果当时核对一句「这个列表里的元素是专辑还是歌单」，第一版就不会做出来。

---

### 5.2 `sort` 是个字符串，而我一直在传数字 —— **整条链路卡最久的一处**

**经过**：找到 `play/music/library/albums` 后，我用各种组合试参数：
POST body、GET query、`id` / `ptypeId` / `pTypeId`、`pn` 从 0 从 1、`sort` 传 `0` 传 `"0"`……
**全部返回 `200` + 空对象 `{}`**。

**真相**：`sort` 是**字符串** `"1"`（精品）/ `"2"`（最新），不是数字。
传数字时服务端回 **`200` + `{}`** —— **不报错**，看起来就像"参数不全"或"这个分类没有内容"。

**怎么找到的**：最后**回到解包**，在 `_AlbumSection` 的构造里读到字面量：

```
"精品" → "1"        "最新" → "2"
```

**这是本该第一步就做的**：`sort` 的取值在反编译产物里是**明文常量**，
而我在它上面**试了十几轮请求**。用户中途明确制止过（「別这样搞，解包没有参数吗？？？」），
我停了一轮，然后又回去试了几轮 —— **这是本轮最该被批评的一点**。

---

### 5.3 「需要移动端请求头」是假的 —— **一个变量传错，污染了对另一个变量的判断**

**经过**：早期用 POST 打这个端点得到 `500`，用 GET + 桌面头得到空数据。
我据此在文档和代码注释里写下「**要移动端请求头**：`plat: android` + 移动端的 `ver`，桌面头会 500」。

**真相**：那个 `500` 是 **POST** 造成的；那个空数据是 **`sort` 传错**造成的。**两者都与请求头无关。**
修好 `sort` 之后重测四种头组合（`plat=win/ver=1.1.7` × `plat=android/ver=5.9.8`），**结果完全一致**。

**教训**：**两个变量同时错的时候，别急着给任何一个下"必需/不必需"的结论。**
当时应该做的是「固定一个、只动另一个」的对照，而不是把两个观测拼成一个因果故事。

---

### 5.4 我写下过四条后来被自己推翻的结论

| 我写过的 | 实际是 | 怎么发现的 |
| --- | --- | --- |
| 「`service/collect/2` 是 PC 端独有的字面量」 | **HTTP 404**。那是**字节级匹配的假阳性**（`service/collect/` 与下一条池常量在内存里相邻被粘在一起） | 用户实测报 404 |
| 「安卓端不存在收藏专辑这个功能」 | 措辞错了 —— 是**安卓端**没有，**桌面端有**（`left_my_collect_album.dart`、`favAlbumList`）。我却拿桌面端的标识符去搜安卓端，零命中就下了结论 | 用户坚持「我说有就是有」，重查后确认 |
| 「`collect/6/list` 的数组键是 `favAlbumList`」 | 该端点实测 200 但 `data` 是空对象；**最终用 `collect/4/list`** | 实测 |
| 「收藏的专辑要靠推断」 | `sourceType: 6` 是**桌面端自己缓存里的真实数据**（`histAlbumList.json`） | 用户收藏一个专辑后去读缓存 |

**共同点**：**每一条都是「用间接证据推出直接结论」。**
`strings` 里能匹配到 ≠ 路径存在；搜不到 ≠ 功能不存在；响应里有 `6` ≠ URL 参数是 `6`。

### 5.5 测试断言写松了，把一个真 bug 放过去了

**经过**：AI 歌单详情我把 `?index=N` **写进了 path**，而传输层还会再拼一次 query，
于是发出去的是 **`...aiPlaylistDetail?index=3?`**（末尾多一个 `?`）—— 服务端回 **400**。

**而我的测试写的是**：

```csharp
Assert.Contains("service/home/aiPlaylistDetail?index=3", url);
```

坏 URL 里**那个子串照样成立**，所以**测试全绿、bug 送到用户手上**。

**修法**：改成守真正的性质 —— **整条 URL 只许有一个 `?`**：

```csharp
Assert.Equal(1, url.Count(character => character == '?'));
```

`Contains` 和 `StartsWith` 都看不见多出来的字符，**只有数 `?` 才看得见**。

**这是本项目里第二个"测试守错了对象"的例子**（第一个是歌词那条）：断言要盯**性质**，不是盯**前缀**。

## 三、走不通的路（都判定完了，别再试）

| 手段 | 结果 |
| --- | --- |
| `adb logcat` | 波点**完全不往 logcat 打**（清空后复现操作，5600+ 行全是系统日志，没有任何 app tag） |
| xlog 文件 | 别的 app 都写在 `/sdcard/Android/data/<包>/files/xlog/`，**波点不写**；它的在私有目录，`run-as` 返回 `package not debuggable`，无 root 读不到 |
| MITM 抓包 | **不行**。`network-security-config` 里 `user` 证书只挂在 `debug-overrides` 下，而 `debuggable:0` → release 包不信任用户证书；且包带腾讯加固（`libturingga`/`libtmeshield`），重打包注入也走不通 |
| 明文日志上报 | **能解开**（XOR 密钥 `Z9o+Lw@H`，见 `reverse/tools/kwlog.py`），但内容是**错误日志**，不含请求 URL；而且**让请求失败也没产生新的上报** |

**结论：不带 root，无法观测这个 app 的请求。**

> **顺带一个反直觉的观测**：那条被抓到的日志上报，`user-agent` 是 `Dart/3.11 (dart:io)` ——
> 说明**波点的 Dart 网络栈确实走了系统代理**（"Flutter 不理系统代理"的常见说法在这里不成立）。
> 所以代理是通的，**纯粹卡在 TLS 解密**。

## 四、工具链的坑（5.9.8 arm64 拉进 blutter 时踩的）

**背景**：应用宝按机型分发，此前拿到的 5.9.8 是 **armeabi-v7a**，blutter 处理不了；
换到 **arm64-v8a** 之后最新版第一次可反编译。两个环境坑：

1. **blutter 的 `CMakeLists` 只在检测到 MSVC 时才设 `ICU_ROOT`**（`if (MSVC)`）——
   不在 `vcvars64` 环境里跑会报 `Failed to find all ICU components`。
2. **失败的 cmake 会把 `ICU_INCLUDE_DIR-NOTFOUND` 缓存住** ——
   之后即使环境对了也照样失败。**改环境后要删 `_tools/blutter/build/dartvm<版本>_<arch>/` 再来。**

复跑脚本：`reverse/tools/run_blutter_598.bat`。

## 五、这一轮真正学到的（写给下一个人）

| # | 教训 |
| --- | --- |
| 1 | **用户描述里的名词是硬约束。** 用户说「专辑合集」，做出来的是歌单 —— 那一步就该停下来核对，而不是继续往下做 |
| 2 | **别用「试」代替解包。** `sort` 的取值在反编译产物里是明文常量，我在它上面试了十几轮请求。**能用零请求解决的，不要发请求** |
| 3 | **两个变量同时错时，做对照，别拼因果。** 「需要移动端头」这个假结论，同时污染了文档和代码注释 |
| 4 | **`strings` 能匹配 ≠ 路径存在；搜不到 ≠ 功能不存在。** 前者是字节粘连，后者是命名不同 |
| 5 | **blutter 会漏字段名**，在两处：**空值检查的报错路径**（`r9 = _categoryItem`）与**字段访问的池引用注释**（`Field <MusicLibCategoryItem.id>: late (offset: 0x8)`）。**这比读 `mov`/`stur` 的裸偏移可靠得多** —— 解开 `pTypeId`/`cTypeId` 靠的就是它 |
| 6 | **断言盯性质，不盯前缀。** `Contains` 看不见末尾多出来的 `?`；数一下才对 |
| 7 | **一个变量传错会污染对另一个变量的判断。** 排查时要知道自己「同时动了几样东西」 |
