# 应用动画

更新日期：2026-10-07。本文记录当前动画实现、生命周期约束和验证结果。

## 交互行为

| 交互 | 当前行为 |
| --- | --- |
| 侧栏 / 页面导航 | 新页面淡入并小幅滑入，返回使用相反方向；重复进入同一页面不重跑生命周期 |
| 页内 Tab | 胶囊选中背景移动并适配宽度，内容按页签方向淡入；设置页分类内容小幅向上进入 |
| 发现页横向卡片 | 旧内容沿翻页方向滑出、淡出，再替换当前页；新内容从对应方向进入，移动范围由视口裁剪 |
| 点击单曲 | 播放确认后，点击位置的封面沿加速下坠轨迹缩入播放条；首播等待播放条封面完成有效布局 |
| 歌手 / 歌单 / 专辑详情 | 来源头像或封面移动、缩放到页头，返回时缩回原页面对应的可见卡片 |
| 多歌手选择框 | 在弹窗关闭前捕获选中的头像，再移动、放大到歌手详情页头部 |
| 播放条进入歌词页 | 播放条小封面放大到歌词页大封面，歌词内容和背景配合淡入 |
| 歌词页收起 | 大封面缩回播放条，歌词内容和背景淡出；封面交接结束后卸载页面 |
| MV 收起 | 页面向下退场并淡出，直接返回原常规页，跳过栈中的歌词页；没有封面缩小或画面缩放 |
| 主题切换 | 正常应用主题后，独立的轻微遮罩在 650 ms 内淡出，保留实时内容和完整主题样式 |

上述新增动画遵循 Windows 的动画开关。关闭动画时直接完成交互。动画不创建离屏列表项，不强制滚动用户的列表。

## 实现入口

文件路径均相对仓库根目录。

| 文件 | 职责 |

| `src/Bodian.WinUI/Controls/Motion.cs` | 标记 Tab 内容、共享封面身份和宿主裁剪；只动画内容根节点 |
| `src/Bodian.WinUI/Controls/PillTabBar.xaml.cs` | 选中指示块的位置、宽度与方向过渡 |
| `src/Bodian.WinUI/Services/CoverTransitionAnimator.cs` | 统一的封面飞行层、详情往返、歌词封面交接；复用现有图像源 |
| `src/Bodian.WinUI/Services/CoverDropAnimation.cs` | 捕获单曲点击来源，确认播放结果后启动下坠 |

| `src/Bodian.WinUI/Services/ThemeTransitionAnimator.cs` | 独立合成遮罩；不修改主题资源、控件颜色、整窗透明度或页面变换 |
| `src/Bodian.WinUI/Services/ThemeColorMotion.cs` | 正弦缓动采样，当前供遮罩透明度关键帧使用 |
| `src/Bodian.WinUI/Services/NavigationService.cs` | 导航提交、沉浸页离场等待、共享封面准备与启动 |

通用交互约 150–260 ms；详情封面往返约 340–420 ms；沉浸页展开约 440 ms；歌词封面放大 520 ms、回位 420 ms；单曲下坠 620 ms；主题遮罩 650 ms。关键帧时长是设定值，日志中的实际结束时间还包含合成提交和 UI 回调调度时间。

## 共享封面与首次布局

`Motion.SharedCoverKey` 用模型类型和 id 关联同一元素，例如 `artist:10208`、`playlist:100169846`、`track:125609`。详情页页头元素命名为 `DetailCover`。圆形头像和圆角封面分别保留对应裁剪，裁剪尺寸考虑宿主缩放。

首次进入时，目标页面尚未触发 XAML 的 `Loading`，导航直接从页面模型取得封面标识；等 `Loaded` 后再测量目标位置。首播会首次显示播放条曲目信息，`Started` 通知早于有效布局，因此保留点击快照，等待目标可见并完成布局后再下坠。这项等待不阻塞音频播放；目标两秒内仍未就绪时跳过动画。

共享层同时只保留一张飞行封面。交接期间隐藏来源和目标的实际图像，完成或取消后恢复；图像源变化、元素卸载和窗口尺寸变化也会恢复可见性。新的请求终止上一轮过渡。

返回只使用仍属于原页面、模型身份匹配且当前可见的落点。原卡片已离屏、已回收或数据被移除时，使用普通内容过渡。多歌手弹窗关闭后的头像不再作为返回目标。

## 导航与 MV 生命周期

播放请求即时处理，普通页面在完成内容切换后播放入场动画。沉浸页离场等待视觉交接结束，再执行页面生命周期和内容卸载；过渡中重复返回或选页时只提交最后目标。

常规页保留在外壳中作为歌词/MV 展开、收起的背景，导航通知仍遵守先离场、后进场的顺序。MV 仍先执行 `VideoSurface.SetMediaPlayer(null)`，再释放播放器。

MV 的“退出 MV”调用 `ExitImmersiveToShell`，使用 `GoBackTo` 跳过栈中的沉浸页，只提交一次返回。不能逐层调用 `GoBack`：经过歌词页会再次触发歌词封面回位。“只听歌”的逐级返回入口保留原语义。

## 主题过渡与资源约束

主题样式由 `ThemeResource` 正常解析。遮罩使用私有 `CompositionColorBrush` 和独立 `SpriteVisual`，以旧主题色的 18% 强度柔和退场；背景、文字、边框与氛围背景的资源值由主题本身管理。

实现必须保留以下约束：

- 不以资源字典中的共用画刷或控件颜色属性作为动画目标，避免污染浅色、深色和高对比度样式。
- 不创建整窗 `RenderTargetBitmap`，避免栅格化开销和动态内容被截图定格。
- 不动画整窗透明度、缩放或位移，避免干扰歌词、频谱、封面飞行和页面切换。
- 先写入动画终值作为底值，再启动显式动画；启动后再写同一属性会提前终止动画。
- 遮罩常驻独立合成层，XAML 首次布局和主题资源更新不会覆盖其透明度动画。
- 新请求、卸载或关闭时取消遮罩；窗口按钮配色与托盘更新合并为一次低优先级任务，深浅两版图标复用至窗口关闭。

先前的整窗快照造成动态画面定格；直接动画画刷 `Color` 引发 XAML 未处理异常，共用画刷重复目标和资源覆盖又造成过渡失败及浅色样式回归。最终实现完全撤回画刷颜色动画，以独立合成层隔离主题过渡。

## 诊断

给应用进程设置 `BODIAN_LYRICS_DIAGNOSTICS=1`，可在现有日志中查看：

- `共享封面准备`、`共享封面动画启动/结束`：封面身份、来源和目标矩形。
- `共享封面等待首播目标布局`：首播目标尚未完成布局。
- `共享封面回退`：来源或目标不可见，使用普通页面过渡。
- `主题遮罩过渡启动/结束`：设定时长、实际结束时间与应用主题耗时。

诊断默认关闭。接口与播放行为不因诊断开关改变。
