# 歌词页外观调节

**日期：2026-10-26。** 全屏歌词页的字体、字号、对齐、高亮色与行距改为页内可调，
入口放在底部传输组「播放模式」左边。**2026-11-05 增加封面样式：方形封面 / 黑胶唱片。**
**2026-11-05 增加封面模糊背景的暗度、模糊强度与未高亮歌词不透明度。**

## 入口与面板

外观按钮只在全屏歌词页出现，位于播放模式按钮左侧，按钮里是一个字母 `A`，
提示「歌词外观」。点击后从窗口左侧滑出一张宽 360 DIP 的浮卡，形态与评论面板一致：
位于标题栏与底栏之间，圆角 16，从左侧滑入；高度随内容收缩，窗口过矮时内部滚动；
点空白处、右上角关闭按钮或按 `Esc` 收起。面板盖住封面、让右侧歌词保持可见，
调字号和间距时能直接看到效果。

底色使用应用统一的 `BowenAcrylicBrush`；设置里关闭「亚克力效果」时同一刷子退回实色兜底。
外观面板与评论面板互斥，打开一个会收起另一个。

面板不显示英文分组名，只保留中文标题与数值。字体一行是「字体」标签 + 选择器；
字号与行距放在同一组里上下排列，各带一个恢复默认按钮，滑杆两端分别是 `A-` / `A+` 与 `−` / `+`。
对齐沿用评论面板的「推荐 / 最新」分段按钮：三颗 32 高的胶囊放在一块凸起底上，
选中项用品牌强调色底 + 深色字，只亮当前一档。对齐下面还有水平 / 垂直偏移两条滑杆，
在对齐结果之上继续微调：水平范围 ±30% 歌词区域宽度，垂直范围 ±25% 歌词区域高度，
正值分别向右、向下。「歌词颜色」分组里，高亮色是一排圆点，下面一条滑杆调未高亮歌词的不透明度；
后者对所有背景模式生效，亮背景看不清非当前行时直接调高。
字号、圆角、间距与强调色都取 `Tokens.xaml` / `Theme.xaml` 的既有 token，不另造一套。

### 控件回填不能发生在页面构造阶段

面板控件只在打开时回填。页面构造时给 `Slider.Value` 赋初值，WinUI 会在控件加载后补发一次
`ValueChanged`；那一刻回填守卫已经撤掉，于是把滑杆的默认值写回设置。2026-10-26 实测：
退出应用再进来，字号从 56 变回 24、文件里留下 `"FontSize": 24`。现在构造函数不碰面板控件，
`OnLyricsFontSizeChanged` / `OnLyricsLineGapChanged` / 字体选择回调都只在 `_appearanceOpen`
为真时写回。

传输组由五颗变六颗后，为了让播放/暂停仍落在窗口水平中线，外观按钮与右侧
36 DIP 空占位对称放置，中间原有的五颗位置不变。

## 黑胶唱片封面

左侧封面区有两种样式，在外观面板「封面」一行二选一，默认「方形封面」。
两种样式共用同一个 `DetailCover` 元素和同一份 `Player.CoverImage`：切样式不重新取图，
共享封面动画的目标也始终是它——进入歌词页时封面飞向中心标签并缩成圆形，
离开时从标签飞回播放条卡片。所以黑胶模式不能隐藏封面元素，也不能换一份图片实例。

- **方形封面**：沿用原来的圆角 16 卡片、半透明白底与下方矩形倒影。
- **放台**：最外层是占封面槽 94% 的底盘，颜色比唱片略浅并带一圈细描边，
  唱片（88%）压在它上面，形成「唱片放在播放器上」的一圈台沿。
  放台不在滑动层里：换碟时唱片滑走，台面留在原地。
- **黑胶唱片**：唱片右上角空出来放枢轴；当前封面按盘径的 56% 缩成中心圆标签（接近半盘），
  中心再叠一个轴孔；纹路是 28 道很淡的细圈，挤在盘径 0.60–0.985 的最外圈，
  相邻两道只差约 1.4% 盘径，不画成几道宽环。
  放台、圆盘、纹路、标签与唱臂全部按封面槽尺寸（140–580 DIP）的比例重算，不写死像素。
- **转动**：播放时整张碟（盘面、纹路、中心封面）绕中心匀速旋转，20 秒一圈（18°/s）。
  每次进入歌词页把角度归零，封面从正向开始转；入场飞行期间先不转，
  落位后再接着转，避免旋转中的方形包围盒把共享封面的落点带歪。
  暂停、窗口不可见、最小化或渲染挂起时停下并记下当前角度，恢复时从同一角度继续。
  拖动进度条或点歌词触发跳转后，声音接上之前唱片同样停住：`PlayerViewModel.IsSeekPending`
  跟随引擎的 `SeekPending` 事件，判据与歌词时钟一致——位置越过目标 50 ms 才恢复，
  避免出现「歌词卡住、唱片还在转」。
  角度由 60 Hz `DispatcherQueueTimer` 直接写 `RotationAngleInDegrees`：
  合成器循环动画在部分机器上一圈后会停住，定时器则始终匀速、可精确暂停。
- **唱臂**：一根圆头 `Path`，枢轴在盘外右上角、贴近封面槽上沿——上段占封面槽 20%、
  竖直向下，折点处用二次贝塞尔过渡成下段（13%、朝左下伸到盘缘），不是两根直杆硬拼；
  曲线半径只取较短段长度的 28%，上下两段主体仍是直线。末端唱头与下段同角度。
  枢轴上移是为了让上段够长又不把唱头推进唱片里。
  播放时整臂在 0° 姿态，唱头落在最外圈纹路上；暂停时绕枢轴转到 +60°，
  整根臂抬到唱片外。360 ms 缓动；唱臂不跟随圆盘旋转。
- **倒影**：矩形倒影在黑胶模式下隐藏——圆形盘面套用矩形采样会露出四角；
  切回方形封面时恢复。
- **暂停缩放**：方形封面原有的「暂停缩到 0.94」只在方形模式生效，黑胶模式保持 1.0，
  避免整台唱片机跟着缩小。
- **换碟**：切歌时按四拍走——旧封面遮罩立刻盖上（绑定已把标签换成新图，晚盖会露出下一首），
  唱臂抬到待机角，旧碟滑出，新碟从另一侧滑入，最后只有仍在播放时才落针。
  方向跟随切歌方式：下一首（含自动连播）时旧碟向左、新碟从右；上一首时反向；
  点选、恢复等其他方式按下一首处理。方向由 `PlaybackCoordinator.LastMoveDirection`
  经 `PlayerViewModel.TrackChangeDirection` 带到页面。
  位移只在唱片的裁剪区里进行，放台、倒影和唱臂都留在原地；连续切歌时版本号让上一轮未完成的步骤作废。
- **沉浸入场**：沿用原有流程，封面槽与歌词一样分层淡入；共享封面飞行在黑胶模式下
  落点变成中心标签，圆角由标签的 `CornerRadius` 提供。中心标签本身不旋转，
  所以落点按标签外框测量始终吻合，不会出现旋转包围盒被放大的偏差。

## 字体与设置页同步

字体只有 `LyricsViewModel.FontFamily` 一份数据。设置页的「歌词字体」和歌词页面板
都读写同一个属性（`SetFontFamily`），两边改哪边都同步，不存在两份配置。
面板的字体列表与设置页相同：首项「默认字体」，其后是 `FontSettingsViewModel.Fonts`。

## 字号不再跟随窗口

此前字号按窗口尺寸计算（窗口高度的 5% 与宽度的 2.5% 取大者，再夹到 24–80 DIP）。
现在由面板给定固定 DIP，窗口缩放不再改变字号。见 `fullscreen-lyrics.md`。
译文行默认按当前字号的 72% 排版（`LyricsRenderSettings.TranslationFontScale`），
可在面板的「译文」分组调到 50%–100%，调字号时译文按同一比例跟随。
同一分组还能关闭「同步高亮」，让译文保持未播放行的暗色，不跟随原文扫色。

## 渲染层处理

- **对齐**：`CanvasTextFormat.HorizontalAlignment` 取左/中/右；排版宽度仍是
  `视口宽度 - 28`。绘制原点按对齐方式补偿，保证居中时文字中心落在窗口中线、
  居右时右缘保留 8 DIP 边距：居左 x = 8，居中 x = 14，居右 x = 20。
  点击选句的底块仍从歌词列左缘铺到右缘。
- **高亮颜色**：只作用于当前行的已唱部分与长音发光，不随高亮色染色。
  未播放行与当前行的未唱部分都按 242 alpha 乘 `InactiveLineOpacity`，
  所以一行变成当前行时未唱文字不会先变暗；调整不透明度时两者同步变化。
- **行距**：直接作为行与行之间的额外间距。文本自身行高是 `1.35 × 字号`，
  所以行距为 0 时相邻行也不会重叠。行距、字号、对齐、字体都参与排版缓存键；
  原文与译文之间的间距由「译文间距」单独控制（0–32 DIP，默认 6），
  与普通行距互不牵连。改动会重建整份排版并重新对齐当前行。
- **边缘模糊**：按行中心离视口上 / 下边缘的距离取整数模糊级，中部清晰，越靠近边缘越糊；
  浏览时锚点行与鼠标悬停行不模糊。模糊级取整数，滚动时不会每帧重建位图。
- **封面模糊暗度与强度**：暗度是叠在背景层上的黑色蒙版，与自定义图片的暗度走同一条
  `BackgroundDimLayer`；强度直接改 `LyricsBackdrop.BlurDip`。两者只在「封面模糊」模式显示，
  不读写自定义图片的暗度 / 模糊字段。
- **未高亮歌词不透明度**：`LyricsRenderSettings.InactiveLineOpacity` 原来固定 0.38，现在可调
  0.2–1.0。调整时只丢弃每行的 `PlainImage` / `BlurredImage` 并重画，字形遮罩与排版保持不变。
- 未播放行、悬停行与当前行仍共用同一份字形遮罩、DPI 与原点。

## 存储

`lyrics.json` 字段如下，旧文件缺少某个字段时取该项默认值：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `FontSize` | number | 24–80，越界夹取 |
| `Alignment` | string | `Left` / `Center` / `Right` |
| `HighlightColorArgb` | number | `0xAARRGGBB`，写盘时 alpha 归一为 `FF` |
| `LineGap` | number | 0–64，越界夹取 |
| `SyncTranslationHighlight` | bool | 译文是否跟随原文同步扫色，默认 `true` |
| `TranslationFontScale` | number | 0.5–1，译文相对歌词字号的缩放，默认 `0.72` |
| `TranslationLineGap` | number | 0–32，译文与原文之间的 DIP，默认 `6` |
| `EdgeBlurRatio` | number | 0–0.5，视口上下边缘的模糊范围，默认 `0.2` |
| `CoverStyle` | string | `Cover` / `Vinyl`，默认 `Cover` |
| `BackgroundMode` | string | `CoverBlur` / `Mica` / `CustomImage` / `SolidColor`，默认 `CoverBlur` |
| `CoverBlurDim` | number | 0–0.8，封面模糊背景的黑色暗度，默认 `0.2` |
| `CoverBlurAmount` | number | 0–80 DIP，封面模糊强度，默认 `52` |
| `InactiveLineOpacity` | number | 0.2–1.0，未高亮歌词不透明度，默认 `0.38` |
| `BackgroundImageFile` | string | 背景图片文件名，位于应用数据目录的 `backgrounds` 下 |
| `BackgroundImageDim` | number | 0–0.8，图片上的黑色暗度，默认 `0.6` |
| `BackgroundImageBlur` | number | 0–40 DIP，图片模糊量，默认 `8` |
| `BackgroundImageFocusX` | number | 0–1，水平裁剪中心，默认 `0.5` |
| `BackgroundImageFocusY` | number | 0–1，垂直裁剪中心，默认 `0.5` |
| `BackgroundImageZoom` | number | 1–3，在 cover 基础上的缩放，默认 `1` |
| `BackgroundColorArgb` | number | `0xAARRGGBB`，纯色背景，默认 `0xFF24324A` |
| `BackgroundCustomColorArgb` | number | 最近一次自定义色，默认 `0xFF24324A` |
| `BackgroundColorAuto` | bool | 纯色背景是否跟随封面取色，默认 `false` |
| `HorizontalOffsetPercent` | number | -30–30，占歌词区域宽度，正数向右 |
| `VerticalOffsetPercent` | number | -25–25，占歌词区域高度，正数向下 |

`LyricsSettings.Normalized()` 逐项夹取，不因某一项越界把其它选择一起退回默认。

## 验收清单

1. 进入歌词页，外观按钮出现在播放模式左侧；播放/暂停仍在窗口水平中线。
2. 点击按钮，面板从左侧滑出并盖住封面；宽度 360、高度随内容收缩，点空白处、关闭按钮、`Esc` 或再点一次按钮都能收起。
3. 打开评论面板会收起外观面板，反向亦然。
4. 设置页开启 / 关闭「亚克力效果」后，面板底色在真模糊与实色兜底之间切换。
5. 面板不显示英文分组名；「字体」标签与选择器在同一行，字号 / 行距滑杆两端是 `A-` / `A+` 与 `−` / `+`，偏移滑杆两端是 左 / 右、上 / 下，恢复按钮可用。
6. 七项都能即时改变歌词；**退出应用再启动**，字号、行距、对齐、水平 / 垂直偏移、高亮色与字体都保持，不被重置。
7. 设置页改「歌词字体」后进歌词页，面板显示同一项；反向从面板改字体，回设置页也是同一项。
8. 对齐分段只有当前一档是品牌色底 + 深色字，另外两档保持中性；三档下文字分别贴左、居中、贴右，当前行选中底块仍覆盖整列。
9. 水平偏移拖到 +30% / -30%、垂直偏移拖到 +25% / -25% 时，歌词在当前位置上向右 / 左、向下 / 上移动；恢复按钮回到 0%。
10. 高亮色改为红/蓝等，只有当前行已唱部分与长音发光变色，未播放行仍是白色；选中色点有品牌色描边。
11. 行距拖到 0，相邻行不重叠；拖到 64 间距明显变大。
12. 「译文」分组里开关同步高亮：关闭后译文不再跟随原文扫色，保持暗色；重新打开立即恢复。
13. 译文大小拖到 50% / 100%，译文相对原文明显变小 / 变大；恢复按钮回到 72%。
14. 译文间距拖到 0，译文贴住原文；拖到 32 明显拉开；恢复按钮回到 6。
15. 边缘范围设为 0 时全部歌词清晰；调到 50% 时上下两侧更大范围逐渐模糊，中部仍清晰；恢复按钮回到 20%。
16. 背景选「封面模糊」时与原来一致；Windows 11 上选「Mica」后歌词页背景变为系统材质，退出歌词页恢复外壳底色。
17. Windows 10 上「Mica」置灰并标注「需要 Windows 11」，背景保持封面模糊；Windows 11 上选中后歌词页背景变为系统材质。
18. 选「自定义图片」会弹出文件选择框；选中后图片按 cover 铺满，暗度按亮度自动给出初值。取消且没有旧图时退回封面模糊。
19. 暗度拖到 0 图片明亮、字可能不清；拖到 80% 明显压暗；模糊拖到 0 保留细节，拖到 40 基本只剩色块；恢复按钮分别回到 60% 和 8。
20. 更换图片后旧图从 `%LOCALAPPDATA%` 的 `backgrounds` 目录删除；原图被移动后背景仍正常显示。
21. 选图后立即弹出「裁剪背景图片」窗口：预览比例与当前歌词页一致，拖动图片选择保留区域，缩放 100%–300%；确定后背景按所选区域显示，取消则丢弃这张图、保持原来的背景。
22. 已选图片后点「重新裁剪…」再次打开同一窗口，初始位置与缩放是上次保存的值；确定后更新。
23. 背景选「纯色」：显示 8 个暗色预设，点击立即生效；「跟随封面」打开后按当前封面自动派生暗色，切歌时更新；关闭后回到手动颜色。
24. 预设行最后一个圆点是「自定义颜色」：圆点始终显示最近一次保存的自定义色，点圆点直接应用该颜色；右下角的小铅笔才是编辑入口，打开色盘后从保存的自定义色开始。选中自定义色时圆点有品牌色描边，切换预设后再点它可回到上次的自定义色。
25. 「自定义」弹窗是 HSV 色盘：角度选色相、半径选饱和度，下方明度滑杆调亮度；点击或拖动色盘、输入 `#RRGGBB`、`#RGB`、`#AARRGGBB`、`rgb(r,g,b)`、`r,g,b` 都能应用，输入非法时确定按钮禁用。
26. 弹窗里左侧是歌词预览：一句用当前高亮色、一句用未高亮的暗白色；右侧是色盘，背景随所选颜色实时变化，颜色偏亮时提示对比度不足。弹窗跟随亮暗主题并使用亚克力底。
18. 面板打开超过 3 秒，底栏不被自动收起；关闭面板后恢复自动收起。
27. 外观面板「封面」可在「方形封面 / 黑胶唱片」间切换，默认方形；切换立即生效，窗口缩放时圆盘、标签、纹路与唱臂按比例缩放，不错位。
28. 黑胶模式播放时唱片匀速转动，暂停停下；暂停再播放从原角度继续，不跳回起点；切歌后中心标签换成新专辑封面。
29. 黑胶模式下唱片外能看到一圈略浅的放台台沿、矩形倒影消失；唱臂是「先下后左」的折线，播放时唱头落在唱片最外圈纹路上，暂停时整根唱臂抬到唱片外；切回方形封面后卡片、倒影和「暂停缩到 0.94」都恢复。
30. 退出应用重启后样式保留；从歌词页返回播放条再进入，共享封面动画正常（飞入中心标签、飞回卡片，无黑块或跳变）。
31. 黑胶模式下切歌：唱臂先抬起，旧碟带旧封面滑出、新碟从另一侧滑入，播放中唱臂随后落回；暂停状态切歌时唱臂保持抬起。下一首时旧碟向左、新碟从右，上一首时方向相反。连续快速切歌不出现两张碟同时停在画面里。
32. 播放时整张碟连同中心封面一起旋转，暂停即停；每次进入歌词页封面从正向开始，入场飞行期间不转、落位后再转，封面飞入中心标签的落点与标签吻合。
33. 背景选「封面模糊」时，面板出现「暗度」「模糊」两条滑杆；切到 Mica / 自定义图片 / 纯色时这两条隐藏，自定义图片仍显示自己的暗度与模糊。
34. 白底或高亮封面下，暗度拖到 40% 以上后未高亮歌词可读；拖到 0 与 80% 背景亮度差异明显；模糊拖到 0 保留细节、拖到 80 基本只剩色块；恢复按钮分别回到 20% 与 52。
35. 「未高亮歌词」拖到 20% / 100% 时非当前行明显变淡 / 接近白色；当前行未唱的文字与该值同步，滚到这一行时不会先变暗再变亮；恢复按钮回到 38%；退出应用重启后保持。
33. 拖动进度条或点击歌词触发跳转、音频还没接上时，唱片停转；声音真正出来（进度越过跳转目标）后从原角度继续，不会出现歌词卡住而唱片还在转。
