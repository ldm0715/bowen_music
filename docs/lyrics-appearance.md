# 歌词页外观调节

**日期：2026-10-26。** 全屏歌词页的字体、字号、对齐、高亮色与行距改为页内可调，
入口放在底部传输组「播放模式」左边。

## 入口与面板

外观按钮只在全屏歌词页出现，位于播放模式按钮左侧，按钮里是一个字母 `A`，
提示「歌词外观」。点击后从窗口左侧滑出一张宽 360 DIP 的浮卡，形态与评论面板一致：
位于标题栏与底栏之间，圆角 16，从左侧滑入；高度随内容收缩，窗口过矮时内部滚动；
点空白处、右上角关闭按钮或按 `Esc` 收起。面板盖住封面、让右侧歌词保持可见，
调字号和间距时能直接看到效果。

底色使用应用统一的 `BowenAcrylicBrush`；设置里关闭「亚克力效果」时同一刷子退回实色兜底。
外观面板与评论面板互斥，打开一个会收起另一个。

面板不显示英文分组名，只保留中文标题与数值。字体一行是「字体」标签 + 选择器；
字号与行距放在同一组里上下排列，各带一个恢复默认按钮，滑杆两端分别是 `A-` / `A+` 与 `−` / `+`。
对齐沿用评论面板的「推荐 / 最新」分段按钮：三颗 32 高的胶囊放在一块凸起底上，
选中项用品牌强调色底 + 深色字，只亮当前一档。对齐下面还有水平 / 垂直偏移两条滑杆，
在对齐结果之上继续微调：水平范围 ±30% 歌词区域宽度，垂直范围 ±25% 歌词区域高度，
正值分别向右、向下。高亮色是一排圆点。
字号、圆角、间距与强调色都取 `Tokens.xaml` / `Theme.xaml` 的既有 token，不另造一套。

| 项目 | 控件 | 范围 | 默认 |
| --- | --- | --- | --- |
| 字体 | `FontPicker`（与设置页同一份字体列表） | 系统已装字体 | 默认字体 |
| 字号 | Slider，步长 1，两端 `A-` / `A+` | 24–80 DIP | 48 |
| 行距 | Slider，步长 1，两端 `−` / `+` | 0–64 DIP | 24 |
| 译文同步高亮 | `ToggleSwitch` | 开 / 关 | 开 |
| 译文大小 | Slider，步长 1%，两端 `A-` / `A+` | 50%–100% 歌词字号 | 72% |
| 译文间距 | Slider，步长 1，两端 `−` / `+` | 0–32 DIP | 6 |
| 对齐 | 评论面板同款分段按钮「居左 / 居中 / 居右」 | 三档 | 居左 |
| 水平偏移 | Slider，步长 1%，两端 左 / 右 | -30%–30% 区域宽 | 0% |
| 垂直偏移 | Slider，步长 1%，两端 上 / 下 | -25%–25% 区域高 | 0% |
| 高亮颜色 | 8 个圆点色板，选中项加品牌色描边 | 白、青绿、蓝、粉、橙、黄、绿、红 | 白色 |

改动即时作用到当前歌词并写入 `lyrics.json`，退出再进、重启应用后保持。
面板打开期间底栏不会被 3 秒自动收起规则收走；关闭后恢复。

### 控件回填不能发生在页面构造阶段

面板控件只在打开时回填。页面构造时给 `Slider.Value` 赋初值，WinUI 会在控件加载后补发一次
`ValueChanged`；那一刻回填守卫已经撤掉，于是把滑杆的默认值写回设置。2026-10-26 实测：
退出应用再进来，字号从 56 变回 24、文件里留下 `"FontSize": 24`。现在构造函数不碰面板控件，
`OnLyricsFontSizeChanged` / `OnLyricsLineGapChanged` / 字体选择回调都只在 `_appearanceOpen`
为真时写回。

传输组由五颗变六颗后，为了让播放/暂停仍落在窗口水平中线，外观按钮与右侧
36 DIP 空占位对称放置，中间原有的五颗位置不变。

## 字体与设置页同步

字体只有 `LyricsViewModel.FontFamily` 一份数据。设置页的「歌词字体」和歌词页面板
都读写同一个属性（`SetFontFamily`），两边改哪边都同步，不存在两份配置。
面板的字体列表与设置页相同：首项「默认字体」，其后是 `FontSettingsViewModel.Fonts`。

## 字号不再跟随窗口

此前字号按窗口尺寸计算（窗口高度的 5% 与宽度的 2.5% 取大者，再夹到 24–80 DIP）。
现在由面板给定固定 DIP，窗口缩放不再改变字号。见 `fullscreen-lyrics.md`。
译文行默认按当前字号的 72% 排版（`LyricsRenderSettings.TranslationFontScale`），
可在面板的「译文」分组调到 50%–100%，调字号时译文按同一比例跟随。
同一分组还能关闭「同步高亮」，让译文保持未播放行的暗色，不跟随原文扫色。

## 渲染层处理

- **对齐**：`CanvasTextFormat.HorizontalAlignment` 取左/中/右；排版宽度仍是
  `视口宽度 - 28`。绘制原点按对齐方式补偿，保证居中时文字中心落在窗口中线、
  居右时右缘保留 8 DIP 边距：居左 x = 8，居中 x = 14，居右 x = 20。
  点击选句的底块仍从歌词列左缘铺到右缘。
- **高亮颜色**：只作用于当前行的已唱部分与长音发光。未播放行固定白色
  （242 alpha 再乘 `InactiveLineOpacity`），不随高亮色染色；未唱部分仍是
  80 alpha 白色。
- **行距**：直接作为行与行之间的额外间距。文本自身行高是 `1.35 × 字号`，
  所以行距为 0 时相邻行也不会重叠。行距、字号、对齐、字体都参与排版缓存键；
  原文与译文之间的间距由「译文间距」单独控制（0–32 DIP，默认 6），
  与普通行距互不牵连。改动会重建整份排版并重新对齐当前行。
- 未播放行、悬停行与当前行仍共用同一份字形遮罩、DPI 与原点。

## 存储

`lyrics.json` 新增四个字段，旧文件缺少这些字段时取默认值：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `FontSize` | number | 24–80，越界夹取 |
| `Alignment` | string | `Left` / `Center` / `Right` |
| `HighlightColorArgb` | number | `0xAARRGGBB`，写盘时 alpha 归一为 `FF` |
| `LineGap` | number | 0–64，越界夹取 |
| `SyncTranslationHighlight` | bool | 译文是否跟随原文同步扫色，默认 `true` |
| `TranslationFontScale` | number | 0.5–1，译文相对歌词字号的缩放，默认 `0.72` |
| `TranslationLineGap` | number | 0–32，译文与原文之间的 DIP，默认 `6` |
| `HorizontalOffsetPercent` | number | -30–30，占歌词区域宽度，正数向右 |
| `VerticalOffsetPercent` | number | -25–25，占歌词区域高度，正数向下 |

`LyricsSettings.Normalized()` 逐项夹取，不因某一项越界把其它选择一起退回默认。

## 验收清单

1. 进入歌词页，外观按钮出现在播放模式左侧；播放/暂停仍在窗口水平中线。
2. 点击按钮，面板从左侧滑出并盖住封面；宽度 360、高度随内容收缩，点空白处、关闭按钮、`Esc` 或再点一次按钮都能收起。
3. 打开评论面板会收起外观面板，反向亦然。
4. 设置页开启 / 关闭「亚克力效果」后，面板底色在真模糊与实色兜底之间切换。
5. 面板不显示英文分组名；「字体」标签与选择器在同一行，字号 / 行距滑杆两端是 `A-` / `A+` 与 `−` / `+`，偏移滑杆两端是 左 / 右、上 / 下，恢复按钮可用。
6. 七项都能即时改变歌词；**退出应用再启动**，字号、行距、对齐、水平 / 垂直偏移、高亮色与字体都保持，不被重置。
7. 设置页改「歌词字体」后进歌词页，面板显示同一项；反向从面板改字体，回设置页也是同一项。
8. 对齐分段只有当前一档是品牌色底 + 深色字，另外两档保持中性；三档下文字分别贴左、居中、贴右，当前行选中底块仍覆盖整列。
9. 水平偏移拖到 +30% / -30%、垂直偏移拖到 +25% / -25% 时，歌词在当前位置上向右 / 左、向下 / 上移动；恢复按钮回到 0%。
10. 高亮色改为红/蓝等，只有当前行已唱部分与长音发光变色，未播放行仍是白色；选中色点有品牌色描边。
11. 行距拖到 0，相邻行不重叠；拖到 64 间距明显变大。
12. 「译文」分组里开关同步高亮：关闭后译文不再跟随原文扫色，保持暗色；重新打开立即恢复。
13. 译文大小拖到 50% / 100%，译文相对原文明显变小 / 变大；恢复按钮回到 72%。
14. 译文间距拖到 0，译文贴住原文；拖到 32 明显拉开；恢复按钮回到 6。
15. 面板打开超过 3 秒，底栏不被自动收起；关闭面板后恢复自动收起。
