# 评论分享卡片与图片导出

**状态：2026-11-13 设计稿，待实现。**

## 目标

- 评论区里的图片可以右键复制到剪贴板、另存到本地。
- 每条评论可以生成一张分享卡片：保留评论正文与用户信息，底部沿用歌词海报的歌曲页脚。

## 1. 图片复制与保存

| 项目 | 行为 |
| --- | --- |
| 入口 | 评论列表缩略图、原图查看器都支持右键菜单 |
| 菜单项 | 「复制图片」「另存为…」；没有可下载原图时不弹菜单 |
| 下载 | 复用应用的 `HttpMessageHandler`（与封面缓存同一份连接池；业务通道固定直连） |
| 复制 | 先解码再统一转成 PNG 写入剪贴板，避免 WebP 等格式在部分粘贴目标里失效 |
| 保存 | `FileSavePicker` 默认落在图片库，保留原扩展名（png / jpg / webp / gif / bmp） |
| 提示 | 成功与失败都走 `INoticeSink`，失败不弹对话框 |

保存走系统文件选择器而不是直接写图片文件夹：与歌词海报一致，用户能看见文件落在哪。

## 2. 评论分享卡片

### 2.1 入口

评论行底部操作区、点赞按钮右侧新增分享图标按钮。列表与回复列表共用同一行模板，因此两处同时生效。

点击后：

1. 取当前曲目的 `Track` 与分享链接；没有曲目时提示「当前没有可分享的歌曲」。
2. 用 `CanvasRenderTarget` 渲染 PNG（与歌词海报同一套技术，不用 `RenderTargetBitmap`）。
3. 打开预览对话框，提供「保存图片」「复制图片」「关闭」。

### 2.2 卡片内容

固定宽度 900、高度随内容自适应，不接歌词海报的字体与配色自定义。

**卡片主题跟随应用当前主题**：亮色为白底深字，暗色为深灰底白字并使用浅色品牌 logo。预览页标题「分享评论」右侧有一颗切换按钮，只切换卡片本身，不改变应用主题；切换后立即用新主题重新渲染。

| 区域 | 内容 |
| --- | --- |
| 头部 | 头像（圆形，缺失时用昵称首字占位）、昵称、发布时间与地点 |
| 回复标记 | 评论是回复时显示「回复 @昵称」 |
| 正文 | 完整内容，不截断；按内容宽度折行 |
| 配图 | 评论带图时按正文宽度等比缩放，圆角，不裁切 |
| 页脚 | 与歌词海报完全一致：左侧品牌图标 + 「波纹音乐」，右侧歌名 / 歌手，右下角歌曲分享二维码 |

正文超过画布高度上限（16000 px）时不出图，对话框显示「评论内容过长，暂时无法生成卡片」。

### 2.3 页脚复用

把 `LyricPosterRenderer` 里的页脚绘制（品牌块、歌名 / 歌手、二维码、分隔线、单行省略格式）抽到 `PosterFooterRenderer`，歌词海报与评论卡片共用。搬移只做方法级抽取，不改任何坐标与字号。

### 2.4 预览对话框

- 单一阶段：打开即渲染，渲染期间按钮禁用。
- 对话框保持紧凑（预览最大 420×460）；**点击预览图可放大查看**，复用 `CommentImageViewer` 的缩放 / 平移 / Esc 关闭，关闭后回到原尺寸。
- 切换主题时旧图保持不动，新图渲染完成后在同一位置淡入、旧图淡出，不隐藏图片、不重新布局窗口。
- 保存 / 复制只认本次渲染的 PNG，失败时显示错误文字并禁用按钮。
- 保存复用歌词海报的文件选择器写法；复制复用 `IClipboardService.SetImageAndTextAsync`，附带歌曲分享链接。

### 2.5 不上报分享数

评论卡片不是曲目分享入口，不调用 `ReportShareAsync`，避免把评论分享计进歌曲分享数。二维码仍指向当前歌曲的分享链接。

## 3. 接线

`SongCommentsPanel` 不直接依赖播放器与窗口：

- `ShareRequested(SongCommentRow)`：由 `LyricsPage` 打开分享对话框。
- `ImageActionRequested(Uri, CommentImageAction)`：由 `LyricsPage` 调用图片导出服务。
- `CommentImageViewer` 同样抛出 `ImageActionRequested`。

`LyricsPage` 额外注入 `HttpMessageHandler`，构造 `CommentImageActions`；窗口句柄、剪贴板、通知、日志本来就有。

## 4. 验收

- [ ] 缩略图右键「复制图片」，粘贴到聊天工具能出图
- [ ] 缩略图右键「另存为…」，默认文件名与扩展名正确，文件能打开
- [ ] 原图查看器右键菜单行为一致
- [ ] 每条评论（含回复）都有分享按钮，位置在点赞右侧
- [ ] 分享卡片包含头像、昵称、时间地点、完整正文与配图
- [ ] 卡片底部品牌、歌名 / 歌手、二维码与歌词海报一致
- [ ] 保存与复制都得到最新一次渲染的图片
- [ ] 亮色应用打开卡片为白底深字，暗色应用打开为深底白字
- [ ] 预览页右侧按钮能单独切换卡片主题，保存 / 复制用的是切换后的图
- [ ] 切换主题时卡片原地淡入淡出，窗口尺寸不跳
- [ ] 点击预览图能放大、平移、缩放，Esc 关闭后回到原尺寸
- [ ] 无网络、图片 404、超长正文都有可读的失败提示
