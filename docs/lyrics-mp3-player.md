# 歌词页左侧：极简播放器

**日期：2026-11-05。** 全屏歌词页左侧封面槽新增第三种样式「极简播放器」：
上方一块宽屏，下方是方向键加中央播放键，按键可直接操作播放。
**已实现**，未提交。

## 1. 结论与边界

- **纯 XAML 矢量，2.5D，不做实时 3D。** 机身、屏幕、按键都按 320 设计稿绘制，
  整层按封面槽尺寸等比缩放。立体感来自哑光渐变、细边与投影。
- **不引入新依赖。** 不需要 Win2D，本样式没有任何逐帧绘制。
- **没有耳机线。** 试过单侧走线、左右分叉与线控，观感都不稳定；这一版只保留设备本体。
- 不走 WebView2 + three.js，也不走 D3D。

视觉目标是「一台安静的设备」：上面一块屏，下面一组方向键，
中央播放键是全画面唯一实心元素。

## 2. 与现有结构的接缝

| 位置 | 改动 |
| --- | --- |
| `LyricsCoverStyle`（`Bowen.Core/Models/LyricsSettings.cs:17`） | 追加 `Mp3 = 2`；设置按枚举名写盘，旧配置不受影响 |
| 外观面板下拉（`LyricsPage.xaml`） | 追加「极简播放器」 |
| `SyncAppearanceControls` / `OnLyricsCoverStyleSelectionChanged` | 由二元判断改为按索引映射三态 |
| `ApplyCoverStyle`（`LyricsPage.xaml.cs`） | 三态显隐；该样式下隐藏倒影、清掉封面槽底色 |
| `UpdateCoverStyleGeometry` | 机身整层缩放到槽尺寸；`CoverFrame` 缩进上方 60×60 图位 |
| `UpdateCoverScale` | 与黑胶一样不做暂停缩放，避免整台机器随暂停缩小 |
| `DetailCover` | 缩成屏幕里的专辑缩略图，**不能隐藏**，共享封面动画依赖它 |

机身按 320×320 设计稿居中，运行时按 `size / 320` 缩放；
`CoverFrame` 的分数坐标（0.275, 0.15625，边长 0.15）与屏幕左侧图位对齐。

## 3. 造型（哑光极简）

| 部件 | 规格 | 画法 |
| --- | --- | --- |
| 机身 | 224×288，圆角 26，槽内居中 | 由外壳颜色派生的竖向哑光渐变 + 一圈 1 DIP 细亮边 |
| 屏幕 | 184×120，机身上半，圆角 10 | 纯平面板（近黑）+ 细描边；不做玻璃、内凹与扫描线 |
| 状态栏 | 屏幕顶部一行 | 左侧电池图标 + 百分比（取系统电量），右侧 24 小时制时钟，每 30 秒刷新 |
| 信息块 | 屏幕内水平居中 | 封面 + 文字整体居中，不贴屏幕左缘 |
| 专辑图 | 48×48，主行左侧 | 复用 `DetailCover`，圆角 5 |
| 曲名 / 歌手 | 主行右侧 | 曲名 12 DIP 最多两行，歌手 9 DIP 次级色 |
| 下一首 | 歌手下方 | 「下一首 · 曲名」8 DIP，没有下一首时隐藏 |
| 进度 | 屏幕底部 | 2 DIP 只读进度线 |
| 方向键环 | 直径 136 圆，机身下方居中 | 外圈按 90° 均分四块扇形，内径 34；每块是独立按钮，扇形之间留 4° 间隙，悬停只换扇形填充 |
| 上 / 下扇形 | 环的上、下四分之一 | 上下箭头；调音量 ±5 |
| 左 / 右扇形 | 环的左、右四分之一 | 左右箭头；上一首 / 下一首 |
| 播放键 | 直径 52，环心 | 浅色实心圆 + 深色图标，全画面唯一实心元素 |
| 投影 | 机身下方 | 径向渐变椭圆，把设备压在桌面上 |

配色克制：屏幕文字与图标灰白，进度线浅灰。

### 3.1 外壳颜色

- 入口：外观面板「封面」下方，选中「极简播放器」时出现。
- 预设：复用纯色背景的 8 个深色；另有自定义色与「跟随封面」开关。
- 自定义色走同一个 `ColorPickerDialog`。
- 跟随封面：与纯色背景共用 `ColorPalette.SolidBackground(seeds, Dark)`，
  但使用独立的 `CoverPaletteLoader`，两边同时开启自动取色时不会互相取消请求。
- 派生：顶部提亮 14%、底部压暗 30% 得到机身渐变；边框用更亮的亮边；
  四块扇形键取比机身浅 5% 的填充，悬停再浅 14%。
- 落盘：`Mp3ShellColorArgb` / `Mp3ShellCustomColorArgb` / `Mp3ShellColorAuto`。

## 4. 交互映射

按钮是真正的 `Button`，键盘焦点、无障碍与按下态都走系统。

| 控件 | 动作 | 绑定 |
| --- | --- | --- |
| 中央键 | 切换播放 | `Player.TogglePlayPauseCommand` |
| 左键 | 上一曲 | `Player.PreviousCommand` |
| 右键 | 下一曲 | `Player.NextCommand` |
| 上键 | 音量 +5 | `OnMp3VolumeUpClick` |
| 下键 | 音量 −5 | `OnMp3VolumeDownClick` |

状态：

- 无曲目时整个槽位隐藏，沿用 `CoverDeck` 现有的 `Player.HasTrack` 绑定。
- 切歌时屏幕缩略图与曲名随绑定更新；不做额外的过渡动画。
- 屏幕上的进度只读，不提供拖拽。

## 5. 动效与性能

- 静态图形只画一次，本样式没有任何逐帧动画。
- 暂停不缩放机身；关闭应用动画时也没有需要停掉的东西。
- 整层用一个 `ScaleTransform` 缩放，所有几何仍按 320 设计稿维护。

## 6. 无障碍

- 五颗按键都有 `AutomationProperties.Name`：音量加 / 音量减 / 上一首 / 下一首 / 播放或暂停。
- Tab 顺序按「上、下、左、右、中」排列，与视觉位置一致。
- 屏幕、底盘与投影不参与命中。

## 7. 现状

- 已实现：三态切换、外观面板入口与持久化、宽屏信息、五颗按键、尺寸缩放、外壳颜色（预设 / 自定义 / 跟随封面）。
- 未实现：频谱接入、按下回弹动效。

## 8. 风险

- **按钮尺寸。** 封面槽最小时约 140 DIP，中央播放键会缩到 23 DIP 左右；
  扇形区域本身够大，重点看中央键在小窗口下是否还点得准。
- **扇形命中。** 四块扇形叠在同一个 136 圆里，模板根节点不能带背景，
  否则每块都会盖住整个圆；改动这个模板时要守住这一点。
- **共享封面动画。** 落点从 320 方卡缩到 60 缩略图，飞入曲线在小目标上的观感需要实测。
- **布局比例。** 屏幕 184×124 与键盘 136 之间的间距固定为 8 DIP（设计稿坐标系），
  缩放后是否显得过挤，需要看实际渲染。
